# ExcelVerticalTab 配布ガイド

この文書は、`ExcelVerticalTab` を他の PC に配布するための実務向けメモです。  
まずは「社内テスト配布」と「正式配布」を分けて考えるのが安全です。

## 1. 配布の考え方

### 社内テスト配布

- 開発 PC で `Release` ビルドと `Publish` を行う
- 開発 PC の証明書ストア上にあるテスト用コード署名証明書のまま配布する
- 利用者側でセキュリティ警告や信頼設定が必要になることがある

短期間の検証や少人数配布なら、この方法が最短です。

### 正式配布

- `Release` ビルドと `Publish` を行う
- テスト証明書ではなく、正式なコード署名証明書を使う
- 配布手順と更新手順を固定する

社内の常用や他部署展開まで考えるなら、こちらを前提にしてください。

## 2. 配布前の前提条件

配布先 PC には次が必要です。

- Windows
- デスクトップ版 Microsoft Excel
- Visual Studio 2010 Tools for Office Runtime (VSTO Runtime)
- .NET Framework 4.8.1 Runtime

開発側 PC には次も必要です。

- Visual Studio 2022 または Visual Studio 2026
- `Microsoft 365 development` ワークロード
- `.NET デスクトップ開発` ワークロード

## 3. 現在のプロジェクト設定

現状のプロジェクトは、配布しやすいように次の前提でそろえています。

- 発行先の既定値は `ExcelVerticalTab/bin/Publish/`
- 発行者名は `ExcelVerticalTab`
- 前提ランタイムは `.NET Framework 4.8.1`
- VSTO Runtime をブートストラッパーに含める

ただし、署名はまだ開発用のテスト証明書ベースです。  
そのため、正式配布の前には証明書の置き換えが必要です。

現在の `Release` 構成は、開発 PC の `CurrentUser\My` に登録したテスト用コード署名証明書で通る状態にしてあります。  
別の PC や別ユーザーで発行する場合は、その環境で証明書を作り直すか、正式なコード署名証明書へ置き換えてください。

## 4. 配布物の作り方

### Visual Studio で発行する

1. `ExcelVerticalTab.sln` を Visual Studio で開く
2. 構成を `Release` に切り替える
3. `ExcelVerticalTab` プロジェクトを右クリックして `発行` を選ぶ
4. 発行先としてフォルダーを選ぶ
5. 既定では `ExcelVerticalTab/bin/Publish/` を使う
6. 発行を完了する

発行時に証明書や VSTO 登録まわりで失敗する場合は、Visual Studio を管理者として起動して再試行してください。

発行に成功すると、通常は次が出ます。

- `setup.exe`
- `ExcelVerticalTab.vsto`
- `Application Files` フォルダー

この 3 点がそろえば、配布用フォルダーとして扱えます。

## 5. 配布先への渡し方

配布先には、発行フォルダーを丸ごと渡します。  
利用者は基本的に `setup.exe` を実行すればよいです。

インストール後は Excel を起動し、次を確認します。

- `Sheet Deck` 関連の UI が出る
- 左側の縦タブ pane が表示される
- シート切り替えができる

## 6. テスト証明書のままで配布するときの注意

現在は開発用のテスト証明書を使っています。  
そのため、配布先で次のような確認が必要になることがあります。

- セキュリティ警告が出る
- 発行元が信頼されていないと言われる
- トラスト センターの設定が必要になる

少人数のテスト配布なら許容できますが、正式配布には向きません。

## 7. 正式配布に入る前にやること

次の 4 点を終えると、配布品質がかなり安定します。

1. テスト証明書を正式なコード署名証明書に置き換える
2. `Release` で発行し、別 PC でインストール確認する
3. インストール手順とアンインストール手順を固定する
4. 更新方法を決める

## 8. 配布前チェックリスト

- `Release` でビルドまたは発行できる
- 発行フォルダーに `setup.exe` と `.vsto` がある
- `setup.exe` は作成済みで、インストーラーとして動作する
- 別 PC でインストールできる
- Excel 起動時に add-in が読み込まれる
- 縦タブ pane が表示される
- シート切り替え、フィルタ、ドラッグアンドドロップが動く
- Excel 終了後にプロセスが残らない

## 9. 補足

VSTO プロジェクトは、ビルドや発行の過程で証明書ストアや Office の登録情報に触ります。  
そのため、コマンドライン実行や権限の低い環境では、`アクセスが拒否されました` で失敗することがあります。

このプロジェクトでも、コマンドラインからの `Release` ビルドでは以下の種類の失敗を確認しています。

- マニフェスト署名の証明書ストア参照
- VSTO の add-in 登録解除処理

Visual Studio からの発行で成功する場合は、まずその経路を正式手順にするのが安全です。
